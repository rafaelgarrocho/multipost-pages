Account and data control

Disconnect and delete your data

MultiPost stores application data locally on the user’s computer. The developer does not maintain a remote MultiPost account database.

Disconnect TikTok

  1. Open Social Media MultiPost on your computer.
  2. Open TikTok Content Posting API settings.
  3. Select Disconnect and confirm.
  4. The application requests token revocation from TikTok and removes the saved local TikTok tokens and account identifiers.

You can also remove access from TikTok’s own security settings. Removing access there prevents future API use even if a local copy of a token remains.

Disconnect Instagram

Remove the app connection in Meta/Facebook Business Integrations, then clear the saved Instagram connection in the local MultiPost configuration.

Delete local content and schedules

Delete posts from the MultiPost interface to remove their local records and uploaded copies. To remove all application data, close MultiPost and delete its local data and uploads folders. Keep a backup only if you intentionally want to retain that information.

Need help?

Open a request on the public support tracker. Never include tokens or client secrets.
