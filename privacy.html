Privacy Policy

This Privacy Policy explains how Social Media MultiPost processes information when a user connects an authorized social media account and uses the local desktop application.

Local-first operation: Social Media MultiPost runs on the user's computer. The developer does not operate a remote MultiPost application server that collects user credentials, tokens, media, captions, or scheduling data.

1. Information processed

Depending on the services enabled by the user, the application may process:

  • basic authorized account information, such as account identifier, username, nickname, and profile image;
  • OAuth access tokens, refresh tokens, granted scopes, and token expiration information;
  • media files, captions, hashtags, privacy selections, and scheduling information chosen by the user;
  • publication identifiers, processing status, and API error information returned by the connected platform.

2. How information is used

Information is used only to authenticate the user's account, display the connected account, prepare requested posts, send user-selected content to the applicable platform, monitor publication status, and renew authorization when permitted.

3. Storage and retention

Application data and credentials are stored locally on the user's device. They remain there until the user removes the connection, deletes the local application data, or uninstalls the application. The developer does not maintain a separate remote copy of this information.

4. Information sharing

When the user initiates a publication or account action, necessary information is transmitted directly from the local application to the selected platform's official APIs. Those platforms process information under their own terms and privacy policies. Social Media MultiPost does not sell personal information.

5. Public website

This informational website does not use developer-operated analytics, advertising trackers, account registration, or contact forms. It is hosted by GitHub Pages, which may process ordinary connection and security logs under GitHub's own policies.

6. Security

Users are responsible for protecting their computer and local project directory. Client secrets and refresh tokens should never be committed to a public repository or shared with another person. Authorization can be revoked through the connected platform's account settings.

7. User choices and deletion

A user may stop processing by disconnecting or revoking the application, removing saved credentials, and deleting locally stored application data. For help identifying the applicable local files, contact support through the link below.

8. Children's privacy

Social Media MultiPost is not directed to children and is intended only for users eligible to use the connected platforms and authorize their accounts.

9. Changes to this policy

This policy may be updated when the application's functionality or legal requirements change. The latest revision date will appear at the top of this page.

10. Contact

Questions, privacy requests, and support inquiries can be submitted through the project's public support page.
