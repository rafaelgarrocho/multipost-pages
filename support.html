Product support

How can we help?

Social Media MultiPost is a local desktop application. When requesting support, never include access tokens, refresh tokens, client secrets, or private media.

Account connection

Confirm that the app’s callback URI exactly matches the URI configured in the platform developer portal, then reconnect the account.

Publishing status

Open the failed post and include the visible error code and log ID in your report. Platform processing can take several minutes.

Disconnect or delete

Follow the account disconnection and data deletion instructions.

Contact support

Open a request on the public support tracker. Do not attach confidential information.

Before opening a request

  • Record the application version and operating system.
  • Note whether the issue affects Instagram or TikTok.
  • Copy the exact error message, error code, and log ID.
  • Remove all secrets and personal information from screenshots.
